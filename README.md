# 🚀 VentureNest

**VentureNest** is an aggregator and accelerator platform that connects **startups**, **mentors**, and **investors** under one ecosystem. We provide early-stage founders with tools, guidance, and access to funding to help them scale their ventures.

> _“Where Startups Take Flight”_

---

## 🧩 Key Features

- 🔗 Aggregator platform for startups, mentors & investors
- 🧑‍💼 Founder registration, startup profile management
- 🧠 Mentor onboarding & discovery
- 💸 Investor matchmaking & portfolio dashboard
- 📝 Pitch submission & funding applications
- 🚀 Acceleration program & cohort tracking
- 🔐 Secure authentication and role-based access
- 📊 Dashboard for progress & insights
